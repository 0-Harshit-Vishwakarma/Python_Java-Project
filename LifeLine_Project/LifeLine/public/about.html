About LifeLine

A simple digital emergency information platform.

LifeLine is designed to keep important personal and emergency information organised in one place. The project focuses on accessibility, clarity and quick access rather than unnecessary complexity.

🧾

One Clear Card

Keep essential personal, medical and emergency contact information together.

📱

Accessible Anywhere

Use the responsive web interface from a desktop, tablet or mobile browser.

📄

Print & PDF

Generate a clean print view and use the browser's Save as PDF option to keep a downloadable copy.

Technology

Built with a simple academic stack.

Frontend uses HTML, CSS and JavaScript. The backend is built with Core Java and the data layer uses JSON files, making the project easy to understand and demonstrate in a BCA viva.
